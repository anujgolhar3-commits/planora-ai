Authorized Redirect URI:

http://localhost:5500/auth/google/callback

Steps in Google Cloud Console:

  1. Enable Google Calendar API in APIs & Services.
  2. In OAuth consent screen, add scopes: calendar.events & calendar.readonly.
  3. In Credentials, create OAuth 2.0 Client ID (Web Application).
  4. Set Authorized Redirect URI to the URL above.
  5. Paste Client ID & Client Secret into .env file.
